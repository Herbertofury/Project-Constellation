# Project Constellation 0.21.0 — Agent Monitor

Candidate source for the Agent Monitor upgrade. Publication and live-browser
acceptance must be reported from recorded results, not inferred from this file.

## Changed

- Restored complete, tree-verified v0.20.1 source into the canonical repository
  root. CI now verifies the actual changed source instead of reconstructing and
  testing a historical carrier archive.
- Added a compact, responsive Agent Monitor with an attention inbox, live chat
  list, browser/profile coverage, search, filters, sorting, exact-chat actions,
  acknowledgement, snooze, diagnostic export, and visible delivery health.
- Added durable first-seen trouble alerts with independent sound and desktop
  notification channels, shared Chromium offscreen audio, Firefox background
  audio, one-shot snoozes, optional bounded reminders and completion alerts.
- Added a portable Rust native hub that merges status observations from Chrome,
  Edge, Opera GX and Firefox sensors. It provides authenticated local transport,
  persisted incidents, browser/profile identities, explicit disconnect state,
  safe cross-browser tab focus, current-user registration and diagnostic CLI.
  Shared mute, volume and delivery preferences are durable hub policy, so any
  connected dashboard controls the elected delivery browser.
- Added a Firefox sensor package. Its development build is unsigned and uses
  temporary add-on installation until a signed distribution is produced.
- Permission prompts are detected for direct user review. Legacy saved
  preferences cannot automatically grant permissions. Drafts are preserved.
- Added regression tests for transport, delivery, stale/reused tabs, browser
  isolation, prompt detection, and responsive dashboard controls.
- Fixed alerts suppressed after mute, acknowledgement from an older run,
  failed playback treated as success, and offscreen-document retirement races.
- Preserved carrier-only Drive guards and project discovery with acknowledged
  persistence; restored every original main test command to the active gate.
- Added a Windows Monitor Kit with the cross-built x64 hub, both browser
  packages, setup commands, offline guides, verification record and checksums.
