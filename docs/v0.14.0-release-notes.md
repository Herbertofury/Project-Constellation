# Project Constellation v0.14.0 — Nightfall

Nightfall turns the v0.13.0 extension into a standalone, production-gated project with a refined identity, modern ChatGPT compatibility, safer authentication, and substantially lower idle overhead.

Highlights:

- New midnight/navy, violet, and electric-blue interface across every owned surface.
- Extremely subtle GPU-composited star layers plus a slowly drifting constellation field, with reduced-motion and constrained-device behavior.
- Repaired Needs Attention/settings persistence and pinned/favorite/archive actions with an in-place IndexedDB v8-to-v10 migration (flag/index repair in v9, Output Vault stores in v10), valid numeric derived index keys, rapid-toggle serialization, and browser-accurate regression coverage.
- Replaced ambiguous checkboxes with accessible ON/OFF switches, automatic save-state feedback, explicit Save Settings controls, and reload-persistence coverage.
- Repaired Approval Autopilot against ChatGPT's current inline **Allow ChatGPT to use …** card and split **Allow ▾** control, including provider-specific conversation-wide permission selection, immediate mount detection, bounded retry, and confirmation that the card actually cleared before success is recorded.
- Added a stale-service-worker fallback that restores saved control state directly from Chrome storage and clearly requests an extension background reload instead of showing false OFF values.
- Added verified count-only recovery so Home reports real local chat/file/knowledge totals even if a non-count section fails, while startup and unavailable states no longer masquerade as zero.
- Current ChatGPT turn/composer compatibility, duplicate-turn repair, and anonymous-chat capture.
- Refresh-safe GitHub device OAuth with rotating tokens and retry-once behavior.
- Google OAuth that cannot report success or ship as production without real provisioning and Drive verification.
- Bounded/deduplicated mutation work, cached tool scans, slower idle/hidden polling, and five-second health context caching.
- Standalone source/history/recovery layout, full manuals/wiki source, CI/release workflows, reproducible verification, artifacts, receipts, and checksums.
- Public privacy policy plus exact OAuth provisioning, production acceptance, and maintainer release runbooks.
- Truthful browser-session coverage for 17 common AI chat sites, with signed-in, guest-ready, sign-in-required, and unverified states kept distinct.
- Always-available **Branch & continue** in Execution Pulse, with durable handoff generation, fresh-chat native-composer transfer, parent/child lineage, capacity-aware urgency, and truthful prefilled/copied fallbacks.
- Always-available **⇄ Output Vault** in expanded and collapsed Pulse modes. A measured shared dock keeps both surfaces visible without collision, while semantic Reader and exact Raw modes present every saved assistant output, files/builds, links, code, generated media, searchable revision history, saved/current comparison, lazy preview, Markdown export, and branch-from-saved recovery.
- IndexedDB v10 immutable output revisions and bounded page-tail snapshots: a provider refresh can no longer overwrite a richer captured final answer with a shorter/tool-only state. Missing responses, links, code, and media are reported as the first-class `output-regressed` state and retained in Drive/GitHub-ready brain snapshots.

Upgrade preserves extension ID `geljambmkfjkhodgkpjhnmfojkpcamig` and local browser storage when reloaded over the existing extension. Export or verify Drive before any major upgrade.

See `CHANGELOG.md` for the detailed change list and `docs/INSTALLATION.md` for installation/upgrade steps.
