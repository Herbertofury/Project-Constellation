# Project Constellation v0.14.6 — Context Lens

## What changed

Chat Pulse rows now explain the chat instead of relying on the browser title alone. The popup and collapsed Execution Pulse navigator show the same canonical context:

- **Task / Last task** — a short, locally captured description based on the newest user request when available.
- **Project** — the canonical Constellation workspace/provider project when known.
- **Now** — for active work, the current observable tool/activity label when it adds information beyond the task.
- Existing provider, state/phase, model, tab-group, age, and direct-focus metadata remain available.

User-created Chrome groups are still preserved and labeled as groups. Constellation does not guess that an arbitrary user group is a project.

## Performance and privacy

The feature adds no provider network traffic. Context comes from Constellation’s existing local IndexedDB catalog and captured turns. New capture batches retain a bounded `lastUserExcerpt` on the chat record so routine Pulse refreshes usually require only a compact chat-record lookup; old records fall back to a bounded reverse user-turn lookup and then use the short-lived context cache.

The ChatGPT MAIN-world transcript proof remains unchanged and metadata-only. Context Lens never sends task text to a remote service.

## Verification target

`npm run verify` must pass, including background live-snapshot coverage, popup Chat Pulse navigation, and the in-page collapsed Pulse navigator. Browser regressions require a vague live title to expose task/project/current-step context without changing focus behavior or user-owned tab-group preservation.
