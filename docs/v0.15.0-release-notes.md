# Project Constellation v0.15.0 — Project Atlas + Compounding Brain

v0.15.0 turns Project Constellation's existing Knowledge Vault and project continuity into a **source-backed compounding Project Brain**, then makes project identity a first-class organizing axis across Home and native Chrome tab groups.

The design is informed by the WikiSkill paper (arXiv:2608.27454): preserve immutable experience, compile it into persistent structured knowledge, keep the active procedure/context compact, and retain rejected interventions instead of forgetting them. Constellation applies that architecture locally and deterministically; it does not send new model requests or inject the whole knowledge vault into provider prompts.

## Compounding Project Brain

- Compiles existing project knowledge into Decisions, Next actions, Strategies, Procedures, Resources, and Versions.
- Builds a bounded **Working set** instead of dumping the full archive into the active surface.
- Keeps exact source-chat/turn provenance and confidence on working memories.
- Shows concurrent Active / Needs attention project chats beside the working context.
- Adds coverage counts for source chats, files, ignored/superseded memories, and pins.

## Memory policy ledger

- **Pin** elevates durable project knowledge.
- **Ignore** removes a concept from working context without deleting its evidence.
- **Restore** brings rejected guidance back.
- Policies are keyed by canonical concept within the project, so duplicate mentions inherit the same choice.
- Re-indexing preserves memory policy/history rather than resurrecting rejected ideas.

## Project Atlas

- Project cards now show Active, Needs attention, and Completed chat counts.
- Organizer defaults to **Project + state**: each project is its own cluster, with Active / Needs attention / Completed / Archived lanes.
- A selected project keeps the same state lanes inside its dedicated view.
- **State lanes** and **Flat** modes remain available and the choice persists locally.

## Project-aware native tab groups

Default managed groups now use project identity when known:

- `PC ✦ 🟣 Project · Active`
- `PC ✦ ⚠️ Project · Needs attention`
- `PC ✦ ✅ Project · Completed`

Completed groups collapse by default while live/attention work remains expanded. The popup adds a **Group tabs by** selector with **Project + state** and **State only**. Chats without a known project use the existing global state groups.

Constellation still never steals tabs from user-created Chrome groups, and every group move is verified before its presentation signature is cached.

## Preserved v0.14.12 safety

Black Box Truth, `uncertain-working`, ACK-backed Work Rescue, No Surprise Navigation, Capacity Guard, Output Vault, recovery, integrity, Drive/GitHub durability, and explicit provider Retry semantics are preserved.
