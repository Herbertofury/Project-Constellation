# Project Constellation v0.17.9 — AI Command Center + Closed-Chat Heartbeat

v0.17.9 is a strict forward-port onto the verified v0.17.8 Scheduled Task Command Center baseline. It preserves the entire v0.17.8 Scheduled Task Guardian/Command Center, provider coverage, project intelligence, privacy boundaries, notifications, and recovery behavior while adding the requested first-party AI chat workspace and QOL hardening.

## Added
- First-party AI Command Center with projects, search, live/attention/completed organization, backups/imports, and safe reopen/focus behavior.
- Gather / Smart Collapse / Stash + Close quick actions with persistence verification and pinned/working/attention safety.
- Native ChatGPT rename and local emoji/color/style decorations.
- Adaptive closed-chat heartbeat with one-shot alarms, bounded authenticated HTML probes, ETag/Last-Modified support, request-governor integration, no hidden provider tabs, no provider auto-reload, 90-minute no-progress dormancy, and absolute six-hour ceiling.
- MV3 manual-close continuity plus Live AI Sessions auto-parking and orphan-watch cancellation.
- Durable completion/attention notifications and repaired Stall & runway alert persistence.
- No-dead-button QOL pass: disabled-state affordances, safe dialog cancel behavior, repeat JSON import, duplicate-tab prevention, and stale-focus recovery.

## Preserved from v0.17.8
- Scheduled Task Command Center and Scheduled Task Guardian.
- Scheduled task observer/page probe and task-health metadata privacy constraints.
- Approval Autopilot, Output Vault, project router/intelligence, existing provider support, and all v0.17.8 safety invariants.
- Existing Chrome permission set; v0.17.9 adds no new permission family.
