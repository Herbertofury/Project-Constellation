# Project Constellation v0.17.1 — Critical Redline

Critical Redline separates hard-stop chat failures from ordinary attention states. Delivery timeout, interrupted/failed sends, refresh-required blocks, dead chat/tool states, and `capacity-reached` are rendered as a dedicated red Critical bucket. Runway watch/handoff, stalls, rate limits, authentication needs, and temporary unavailability remain orange Needs Attention.

## User-visible behavior

- Red title/favicon beacon for Critical chats.
- Red native Chrome group: `PC ✦ 🔴 <Project> · Critical` (or global Critical in state-only mode).
- Critical group stays expanded; only Completed groups auto-collapse.
- Popup Chat Pulse and collapsed in-page Pulse pin expose Critical as a separate filter/count.
- The extension toolbar badge prioritizes Critical over Active/Attention so a hard stop cannot be hidden by another running chat.
- User-created Chrome tab groups remain untouched.

## Hard-stop classification

Critical status states: `blocked-approval`, `delivery-timeout`, `connection-interrupted`, `response-interrupted`, `send-failed`, `refresh-required`. Critical live-health states additionally include `dead`, `tool-dead`, `capacity-reached`, `degraded`, and `stale-page`.

Ordinary warning states such as `capacity-watch`, `capacity-handoff`, `stalled`, `tool-stalled`, `rate-limited`, `auth-required`, and `unavailable` remain Needs Attention.
