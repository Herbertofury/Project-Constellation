# Project Constellation v0.14.5 - Pulse Navigator

v0.14.5 repairs the live-tab count regression and turns the Active / Stale / Completed indicators into useful navigation surfaces.

## Reliable counts

Every supported open AI tab now appears in the canonical Pulse snapshot. A single unresponsive or pre-upgrade tab can no longer make the popup or pinned HUD show `0 / 0 / 0`: each tab probe has a bounded deadline, recent canonical state can be reused briefly, and a tab that cannot currently be inspected is surfaced as **Needs Attention / reconnecting** rather than silently dropped. `openChatTabs`, `responsiveTabs`, and `partial` make this explicit.

Pulse also avoids re-running the ChatGPT MAIN-world deep probe check on every refresh. It reads the already-installed Live Sentinel first and bootstraps the deeper probe only when necessary. Tab and tab-group lifecycle events invalidate the short cache immediately.

## Group behavior

Project Constellation distinguishes its own status groups from user-created groups:

- Tabs in **user-created groups stay in those groups**. They are still counted, listed, tagged, and focusable.
- Tabs in **Constellation-owned status groups** can move between Active / Needs Attention / Completed so automatic sorting keeps working.
- Constellation group mutations are serialized so several chats completing at the same time cannot race and create duplicate status groups.

## Chat navigator

Click **Active**, **Stale**, or **Completed** in either the popup Chat Pulse or the collapsed Execution Pulse pin. A compact live list opens with every matching chat. Each row includes useful provider/state/model/group context and jumps directly to the existing tab. If that tab disappeared, Constellation can reopen its known URL as a fallback.

The popup and in-page pin both consume the same canonical live snapshot and the same focus action, so their counts and destinations cannot intentionally diverge.

## Testing

Regression coverage includes a five-tab Pulse where one tab is deliberately unreachable and another completed chat remains inside a user-created group. The snapshot must report all five tabs, classify the unreachable tab as reconnecting/attention, preserve the user group metadata, and retain correct Active/Stale/Completed counts. Popup and pinned-Pulse browser tests also require the new bucket lists to render every row and navigate the selected chat.
