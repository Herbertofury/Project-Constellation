# Project Constellation v0.17.5 — Project Identity + Semantic Output Guard

This release is a quality-of-life and trust pass over v0.17.4. It makes project assignment feel like a first-class ChatGPT-style workflow and stops Output Vault from treating ordinary provider progress UI as lost work.

## Project identity QoL

- Adds one shared project-identity model for emoji/icon + exact custom color.
- **Current Chat → Add to Project** now supports a searchable existing-project list plus inline Create + add with a curated emoji picker, native color wheel, hex input, presets, and live preview.
- The full Projects workspace uses the same picker when creating or editing a project; there is no second cosmetic-only identity store.
- Project identity propagates into project cards, pinned projects, project clusters, Project Room headers, the current-chat project card, Popup/Pulse project context, and managed Project + state tab-group titles.
- Custom project color is used as a project accent while Critical / On Hold / Active / Needs / Completed keep their own status colors, so project decoration never hides health semantics.
- Exact active-tab/chat revalidation remains in place before assignment. Project QoL does not weaken the “never file the wrong conversation” guard.

## Output Vault common-sense guard

- Output comparison now uses a semantic projection of assistant output instead of raw provider DOM text.
- Ephemeral rows such as **Thinking**, **Called tool**, **Analyzing image**, short search/read/build/verification progress labels, and equivalent provider telemetry are ignored for mismatch warnings when they disappear normally.
- Punctuated final prose and substantive response content remain durable evidence; real truncation, lost links/media/code, and missing assistant turns still trigger protection.
- Raw captured revisions are preserved. The semantic filter only controls whether ordinary UI churn becomes an alarm; it does not delete forensic/recovery history.
- Output checks wait through a short post-generation settling window so provider cleanup immediately after completion does not race the vault comparator.

## Verification guard

- Tightens the UI ownership contract: a button ID merely appearing in JavaScript no longer counts as proof that the button is wired. Direct listeners, form ownership, or recognized delegated handlers are required.
- Adds explicit delegated coverage for Popup chat-bucket cards.
- Replaces the monolithic smoke launcher with per-workflow direct-to-log execution, exact matching/resume controls, a default watchdog, and process-tree termination on timeout.
- Fixes Linux system-Chromium teardown in the live-health stability smoke by explicitly closing the page before the browser.
- Adds dedicated project-identity and semantic-output regression tests, including proof that transient provider progress disappearing is ignored while real substantive truncation is still detected.

## Preserved

- 🛡️ On Hold / Review remains distinct and blue.
- Critical remains red and intervention-only.
- User-created Chrome groups remain untouched.
- Constellation still never automatically sends, retries, reloads, or navigates provider content.
- Production OAuth remains a truthful hard gate; development packages do not pretend Google/GitHub OAuth is provisioned.
