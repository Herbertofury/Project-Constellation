# Project Constellation v0.14.4 - Deep State + Tab Beacons

v0.14.4 moves ChatGPT live-state detection beyond page-text heuristics and finally ships the tab-status system originally planned for Chat Pulse. The extension now combines a sanitized, same-origin ChatGPT transcript probe with exact current-turn DOM evidence, while keeping network traffic as telemetry rather than letting auxiliary requests decide whether a response is still running.

## ChatGPT deep-state detection

- **Transcript-backed generation proof.** A ChatGPT-only MAIN-world probe reads the current conversation transcript from ChatGPT's own same-origin conversation endpoint and reduces it to non-content state metadata. The isolated extension receives only status/progress identifiers such as current node, message status, `end_turn`, model slug, async task ID, widget status, tool count, and an explicit numeric progress value when ChatGPT itself provides one.
- **Explicit completion wins.** A current assistant node marked `finished_successfully` with `end_turn` is authoritative completion proof. It can override a stale Stop button, old `aria-busy`, or auxiliary provider traffic that lingers after the answer is already complete.
- **Explicit running wins.** An unfinished current transcript node can keep a chat Active through temporary DOM gaps while ChatGPT replaces tool/progress surfaces or renders the next answer chunk.
- **Current-turn alignment.** Transcript evidence is matched to the newest visible user turn before it is allowed to override the DOM, preventing a cached/stale transcript from declaring a newly submitted prompt complete.
- **Deep Research awareness.** The probe understands ChatGPT SDK widget state and async-task metadata. When ChatGPT exposes a real numeric task percentage, Constellation can show it; Constellation does not invent a fake percent from elapsed time or DOM mutations.
- **Exact DOM fallback.** If transcript proof is unavailable, ChatGPT falls back to exact current-turn surfaces: `conversation-turn-*` articles, the current assistant's busy state, the exact Stop button, current structured progress rows, and the current answer's Copy control. Generic page-wide loading wrappers and ordinary answer prose are not generation evidence.
- **Transport classification without false positives.** ChatGPT response, Codex-response, and deep-research SSE/task streams are classified in the service worker for diagnostics. They remain telemetry only and cannot resurrect a transcript-proven completed chat.
- **Event-driven completion confirmation.** When an authoritative ChatGPT response/deep-research transport settles, the service worker asks Live Sentinel for an immediate transcript refresh. Normal active transcript polling is deliberately slower, reducing repeated full-conversation reads while preserving fast completion detection.
- **Hot upgrade for existing tabs.** The background worker version-checks and injects the MAIN-world ChatGPT probe, Live Sentinel, and Tab Beacon into already-open supported tabs when possible, so upgrading the extension does not intentionally require refreshing every chat.

## Tab Beacons - actually implemented

Tab status is enabled by default and can be individually customized or disabled from the popup.

- **Status in the tab title.** Active, Needs Attention, and Completed tabs receive configurable status emoji while preserving ChatGPT's real title changes.
- **Dynamic status favicon.** Constellation adds its own lightweight SVG favicon beacon using a user-selected status color without deleting the site's favicon nodes.
- **Native Chrome tab groups.** Managed AI tabs can automatically move between `PC Active`, `PC Needs attention`, and `PC Completed` groups with configurable native group colors. Constellation never steals a tab from an unrelated user-created group.
- **Toolbar beacon.** The extension action badge shows the active-chat count first, then the stale/attention count, and a completed check when supported open tabs are settled.
- **Manual emoji tags.** The current tab can be tagged with presets such as `🔥`, `📌`, `💡`, `🧪`, or `✅`, or a short custom tag. Tags persist by provider/chat identity when possible and appear alongside the automatic status marker.
- **Right-click tagging.** A Project Constellation tab-tag context menu exposes the same common tag presets plus Clear.
- **One state source.** The title, favicon, native group, popup Chat Pulse, action badge, notification transition, and Execution Pulse all consume the same canonical live-tab state instead of maintaining independent notions of running/completed.

## Privacy boundary

The deep ChatGPT probe is intentionally narrow. It runs only in ChatGPT's page world and may make a same-origin transcript request using the browser's existing ChatGPT session. If the normal cookie-backed request is rejected, it may read ChatGPT's in-page session token solely inside the page world and retry the same-origin request. The token and conversation text never cross the `window.postMessage` boundary and are never sent to the extension service worker, Drive, GitHub, Output Vault, or diagnostics. Only the sanitized state envelope is exposed to Constellation.

Other providers continue to use their provider-specific DOM/live-state paths; the ChatGPT transcript probe is not injected on unrelated sites.

## Live browser harness note

`npm run test:live-browser` launches a persistent Chromium/Chrome-compatible profile with the unpacked extension and can query real ChatGPT tab state when the environment permits normal browsing and login. The current build environment has administrator-managed Chromium policies that block external navigation and extension installation, so it cannot truthfully perform an authenticated live `chatgpt.com` acceptance run here. The code and fixtures are tested in real Chromium; the user's normal browser remains the final signed-in acceptance target.
