# Project Constellation v0.18.0 - Smart Project Icons + Chat Menu QOL

v0.18.0 builds directly on v0.17.9 and upgrades project/chat identity so ChatGPT-side organization feels native instead of bolted on.

## Added
- Self-contained project-style vector icon library with no CDN or font dependency.
- Semantic project icon suggestions for Minecraft, magic, combat, repair/tooling, coding, design, research, study, travel, music, security, analytics, botany, animals, crafting, and more.
- Project icon + color picker in the AI Command Center project settings.
- Matching vector icon picker in the side-panel project creator, while preserving custom emoji support.
- Smart chat icon inheritance: confirmed Constellation project first, Command Center project membership next, provider project identity next, then high-confidence smart routing and semantic fallback.
- Related-project family badges so split work such as multiple Spellbrook subprojects can show multiple matching identities without silently moving the chat.
- Chat appearance controls for Auto, Project only, Custom icon, or No icon, plus optional related-project badges.
- ChatGPT native menu augmentation with Appearance + project icon, smart project match, Favorite in Constellation, Pin in Constellation, and Open in Command Center actions.
- Explicit project assignment from the sidebar editor with confirmation metadata and no provider API call.

## Safety and QOL
- No hidden provider tabs, provider reloads, provider fetches, or polling intervals were added.
- Smart matching is visual by default; project assignment changes only after an explicit user click.
- Existing ChatGPT Share/Rename/Pin/Archive/Delete/Move controls are left intact.
- Existing v0.17.9 Scheduled Task, heartbeat, Command Center, notification, and safety behavior is preserved.
