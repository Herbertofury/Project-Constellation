# Project Constellation v0.14.12 — Black Box Truth + Work Rescue

## What this release fixes

v0.14.12 removes the dangerous ambiguity between **quiet but still working** and **actually stalled**. A frozen tool card or stale `running` label is no longer enough to tell you to interrupt a good run. At the same time, meaningful assistant output is journaled as it appears so a provider interruption or page failure is much less likely to erase useful work.

## Black Box Truth

Health Core v10 evaluates independent observable evidence rather than trusting one UI surface:

- sanitized provider/transcript heartbeat and categorical activity status;
- assistant DOM growth and response timestamps;
- tool-step mutation and tool progress;
- response-stream/network lifecycle;
- current-turn ownership and rejection evidence;
- stop-control, composer-busy, and request-lifecycle state;
- provider-final and other contradiction signals.

A fresh provider/transcript heartbeat can prove a run is advancing even when the visible tool card has not changed. A stale `running` claim without corroboration becomes `uncertain-working` with **Activity uncertain · do not interrupt yet** rather than `stalled`.

## Privacy-bounded provider activity

The ChatGPT MAIN-world probe exports only bounded metadata such as phase, categorical operation name, status, progress percentage, and timestamps. It does not export prompt text, answer text, tool arguments, authentication material, or chain-of-thought. Example shape: `deep-research → research_kickoff_tool.start_research_task → running → 42%`.

## Work Rescue Journal

Streaming assistant revisions are sent through a direct rescue commit path in addition to normal batched capture. `PC_RESCUE_TURN_COMMIT` returns success only after the revision and canonical turn writes complete in IndexedDB. Execution Pulse says **saved** only after that ACK.

If the ACK path fails transiently, the newest visible revision remains pending and retries with bounded exponential backoff. A failed older in-flight revision cannot overwrite a newer pending revision that appeared while it was waiting.

## State convergence and incident surfaces

- Healthy/running updates clear stale legacy failure/retry-forbidden metadata.
- Home can show the Health Core proof verdict/certainty and the age/size of the last ACKed Work Rescue commit.
- Needs Attention and its badge include fresh corroborated live-health incidents even when the legacy chat status is still `running`.
- `uncertain-working` is deliberately excluded from Needs Attention and Project Integrity incidents.
- Project Integrity understands fresh tool/request stalls, dead/degraded states, provider interruptions, and Capacity Guard watch/handoff/reached states.

## Preserved safety invariants

Passive monitoring never clicks Retry, opens/focuses/navigates/reloads ChatGPT, or branches a conversation automatically. Provider Retry remains an explicit user action in the already-open tab. Approval recovery remains open-tabs-only.
