# Project Constellation v0.17.2 — Review Hold + Instant Alerts

## What changed

- Adds a dedicated blue **On Hold / Review** state for ChatGPT's explicit “Our systems are thinking a bit more about this request before responding … retry with a faster model …” surface. Constellation treats this as provider review, not as a stall or Critical failure.
- Adds blue state presentation across the live system: 🔵 title prefix, blue favicon beacon, blue native Chrome `On hold` group, Chat Pulse count/filter, in-page Pulse chip, and toolbar-badge priority below Critical but above Active.
- Watches the current-turn review surface with bounded DOM evidence. When the review banner disappears, the same chat exits On Hold immediately and Constellation issues a one-shot **Review cleared** local notification so the user knows to check it.
- Adds explicit local **Chat completed** notifications for live transitions into Completed and explicit **Critical** notifications for delivery timeout, conversation limit reached, interrupted/failed sends, dead chat/tool states, and equivalent hard stops.
- Keeps completion/Critical transition memory in `chrome.storage.session`, so Manifest V3 service-worker suspension does not silently lose the previous live state needed to recognize a transition. State is scoped to the same chat identity and removed with the tab.
- Notification clicks focus the exact existing chat tab. Constellation still never retries, reloads, navigates, stages provider text, or presses Send as a notification side effect.

## State semantics

- **🔴 Critical:** hard stop / intervention required.
- **🔵 On Hold:** explicit provider-review hold; not stalled.
- **⚠️ Needs Attention:** warning/temporary issue such as runway pressure, stalls, rate limits, authentication needs, or temporary unavailability.
- **🟣 Active:** live work.
- **✅ Completed:** finished and ready to check.

## Performance and safety

Review detection is bounded to status/low-emphasis candidates and a small number of siblings after the latest user turn; it does not scan an entire long transcript on every pulse. Existing user-created Chrome groups remain untouched. Provider-write safeguards from v0.17.0 remain unchanged: Constellation may prepare context, but provider-chat content requires explicit user approval and the user presses Send.
