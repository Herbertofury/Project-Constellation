# Project Constellation v0.14.8 — No Surprise Navigation

v0.14.8 keeps Runway Sentinel's v0.14.7 stall/runway detection and removes the legacy Approval Recovery side effect that could create a minimized `chatgpt.com` window after a chat became stalled. Installed-app/PWA link capture could hand that navigation to the Windows ChatGPT app, producing unsolicited app launches/thrashing.

## Invariant

Runway/health monitoring is observation-only. It may update timers, status, badges, tab presentation, Needs Attention and notifications. It may not open, focus, navigate or reload ChatGPT.

Approval Autopilot continues to operate in already-open ChatGPT tabs. Manual recovery scans are open-tabs-only; closed historical chats are skipped rather than opened. Missing Pulse targets are reported as closed instead of being recreated.

On install/update/startup, v0.14.8 also terminates any persisted <=0.14.7 hidden recovery run before normal monitoring starts.
