# Project Constellation v0.16.0 verification receipt

This document is the permanent release-verification receipt for **Project Constellation v0.16.0 — Living Project Rooms + Safe Router**.

## Release gates

The integrated release candidate is required to pass, before publication:

- complete Node unit/regression suite;
- validation, UI contract, and message contract checks;
- development build plus all browser smoke workflows;
- project-scale regression covering **500 projects / 10,000 chats**;
- deterministic installed-extension acceptance in **real Playwright Chromium** with the real unpacked MV3 extension;
- normal pull-request **Verify** on the externally updated final PR head.

## Chromium acceptance scope

The installed-extension acceptance uses a `https://chatgpt.com/c/...` origin fixture fulfilled inside Chromium. This intentionally removes provider CDN, login, and network availability as release-gate noise while preserving Chrome's real manifest host matching and automatic content-script behavior.

The acceptance exercises the actual extension manifest, MV3 background service worker, automatic content-script messaging, provider host permission, scripting API, Live Chat Pulse runtime messaging, extension storage, Stall & runway alert persistence, unavailable-control QOL, Popup-to-Command-Center routing, and Command Center dialog cancel ownership.

It is **real Chromium + the real unpacked Project Constellation extension**, but it is **not a claim that a user's signed-in local Chrome profile or authenticated provider account was exercised in CI**.

## Why this receipt is committed externally

GitHub intentionally suppresses new workflow runs caused by many pushes performed with a workflow's own `GITHUB_TOKEN`. This receipt is committed through the connected GitHub account after the isolated browser/scale gate so PR #21 receives a normal external synchronize event and the repository's standard **Verify** workflow can test the final PR head before merge.
