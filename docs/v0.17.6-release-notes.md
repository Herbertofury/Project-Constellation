# Project Constellation v0.17.6 — Terminal State Truth Guard

This release fixes a hard-stop classification gap exposed by current ChatGPT pages: visible bottom-of-chat provider failures and conversation-limit banners can be ordinary styled DOM rather than ARIA alerts. Constellation now treats those explicit provider terminal surfaces as authoritative even when recent network/tool activity would otherwise look healthy.

## Terminal failure detection

- Detects current-turn **Message delivery timed out**, connection interruption, response interruption, and send failure cards even when the provider renders them as ordinary `div`/`section` content with no `role=alert`, `aria-live`, or error test id.
- Uses native **Retry / Try again / Regenerate / Resend / Reconnect** controls as bounded structural anchors to find the adjacent provider error card without broad page scraping.
- Gives explicit provider terminal failures hard precedence over stale `running`, network, tool, or completion evidence.
- Provider terminal failures are **Critical** (red intervention state), not ordinary stale/attention warnings.
- Removing the provider failure surface clears the terminal state normally; Constellation never clicks Retry automatically.

## Conversation maximum detection

- Detects provider-declared maximum/context/conversation-length exhaustion from current bottom-of-chat UI even when the banner has no ARIA semantics or recovery button.
- Hard provider limits become `capacity-reached / Critical` immediately and cannot be masked by an old active/network signal.
- Proactive local runway warnings remain separate from provider-declared hard exhaustion.

## Long-chat and false-positive hardening

- Status sampling now favors the newest bounded controls instead of the oldest 240 controls on the page.
- Terminal fallback candidates are restricted to the current conversation frontier, preventing an old timeout card higher in a long thread from poisoning the current state.
- Assistant prose that merely quotes phrases such as “Message delivery timed out” is not treated as a live provider error.
- Terminal DOM fallback is bounded to the newest page tail and recognized terminal phrases, preserving observer/performance discipline.

## Pulse / project visibility

- Critical health-state bucketing is honored even when the provider status string is idle, so `capacity-reached` cannot fall into Completed.
- Pulse Needs Attention explicitly renders delivery-timeout and maxed-conversation chats as red Critical rows.
- Popup fallback grouping uses the same health-state-aware bucket rules.


## Trusted connector permission recovery

- Recognizes current ChatGPT host-shaped permission sheets such as **Allow access to drive.google.com** and **Allow access to github.com**, not only older “Allow ChatGPT to use …” wording.
- Treats Google Drive and GitHub as explicit connector identities for recovery telemetry and scoped prompt matching.
- Opens ChatGPT's split **Allow** menu when present and chooses **Allow all** / conversation-wide permission before falling back to a one-time Allow.
- Supports portalled menus and icon-only chevrons, including the exact prompt shape shown in the reported screenshot.
- Requires the permission sheet to disappear before reporting success; an ignored click remains a failure.
- Keeps failure recovery separate: provider **Retry** is still never auto-clicked after message delivery/network failures.

## Verification

- Adds a current-ChatGPT-shape browser regression using a plain timeout `div` plus Retry, with no alert semantics.
- Adds exact Google Drive and GitHub host-shaped permission regressions proving split-menu **Allow all** is selected automatically when Approval Autopilot is enabled.
- Adds a plain hard-limit banner regression with no ARIA semantics and no button.
- Verifies historical timeout cards and assistant-authored quoted error text do not false-positive.
- Revalidates Interruption Guardian, Pulse, Live Sentinel, live-health stability, state convergence, tab beacons, and the complete browser workflow matrix before release packaging.

## Preserved

- 🛡️ On Hold / Review remains its own blue state.
- Constellation does not automatically retry, send, reload, branch, or navigate provider content.
- Output Vault semantic filtering from v0.17.5 remains intact.
- Project emoji/custom-color identity remains intact.
- Production OAuth remains a truthful hard gate when real provider client IDs are unavailable.
