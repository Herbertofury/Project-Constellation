# Project Constellation v0.17.4 — Chrome Stability Guard

This release fixes a real browser-churn regression in the v0.17.x live presentation path without removing the 🛡️ On Hold / Review state or weakening any safety behavior.

## Fixed

- Makes repeated identical Tab Beacon presentations truly idempotent. Reapplying the same state no longer removes and reapplies the same title prefix.
- Caches generated favicon data URIs and avoids rewriting an unchanged favicon URL.
- Stops issuing `chrome.tabGroups.update` when a managed native group already has the correct title and color.
- Removes status-owned collapse behavior completely. Completed groups no longer auto-collapse; an upgrade migration opens groups that older builds collapsed once, then Constellation never changes their collapse state again.
- Stops Constellation-owned tab-group update events from globally clearing every tab-presentation signature and feeding presentation work back into itself.
- Narrows the Tab Beacon title observer to the document title/head construction path instead of leaving a whole-document subtree observer attached when the content script starts before `<title>` exists.
- Narrows Pulse UX mutation handling to Constellation-owned Pulse/Vault surfaces instead of waking on unrelated provider DOM streaming.
- Narrows Live Sentinel attribute mutation handling to the active assistant turn and known live/status surfaces, so unrelated ChatGPT class churn does not schedule health scans.
- Deduplicates persisted live-transition state writes and avoids resynchronizing tab presentation on unchanged Sentinel pushes.
- Restores the tiny in-page Pulse navigator to **Active · Needs · Done**. `Needs` combines Critical + 🛡️ On Hold + Stale only in this compact menu, while the expanded list preserves the exact detailed state for every chat.

## Crash-regression evidence

- **10,000 identical 🛡️ hold presentations:** v0.17.3 produced **20,001 title/favicon DOM mutations**; v0.17.4 produces **0 additional mutations after the initial presentation** (3 total setup mutations in the benchmark document).
- **1,000 already-correct native group reconciliations:** v0.17.3 issued **1,000 `chrome.tabGroups.update` calls**; v0.17.4 issues **0**.
- Repeated unrelated class mutations in a settled ChatGPT-like page produce **0 additional Live Sentinel scans** in the observer-scope regression smoke.
- Completed-group reconciliation performs **0 collapse writes** after migration, including when the user manually collapses a managed group later.

## Preserved

- 🛡️ On Hold / Review remains blue and distinct from Critical, Needs Attention, Active, and Completed.
- Completion, Critical, and review-cleared notifications remain local and transition-gated.
- User-created Chrome groups remain untouched.
- Constellation still never automatically sends, retries, reloads, or navigates provider content.
