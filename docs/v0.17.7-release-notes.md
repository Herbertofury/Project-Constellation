# Project Constellation v0.17.7 - Scheduled Task Guardian

## What changed

Project Constellation now includes a premium-designated **Scheduled Task Guardian** for ChatGPT Scheduled (`https://chatgpt.com/schedules`). The Guardian is designed around Chrome Manifest V3 lifecycle behavior instead of keeping a wasteful normal browser tab alive.

- Reuses the extension's single existing offscreen document.
- Keeps one tiny Scheduled iframe warm when ChatGPT permits extension framing.
- Detects `X-Frame-Options` / `frame-ancestors` blocking and falls back to a lighter authenticated reachability heartbeat rather than retrying a blocked frame in a loop.
- Restores the Guardian after Chrome startup when auto-repair is enabled.
- Uses a bounded alarm cadence: 15, 30, 60, or 180 minutes; default 30 minutes.
- Uses a single-flight supervisor so overlapping alarm/manual checks do not duplicate work.
- Never creates an inactive, minimized, or surprise ChatGPT tab/window. **Open Scheduled** is an explicit user action and opens the canonical page in the foreground.
- Adds Home and side-panel controls for enable/disable, embedded mode, auto-repair, cadence, manual repair, and exact Scheduled navigation.

## Truth boundary

Scheduled tasks are cloud jobs managed by ChatGPT. A browser page does not execute their schedule. Guardian therefore protects the browser/session/management surface and keeps it recoverable; it does not claim that an iframe can override a task paused by ChatGPT for inactivity, required action, deleted source chat, workspace policy, approval, capacity, or provider-side failure.

## Performance and privacy

The Guardian does not add a content-script polling loop, does not read task contents, and does not store Scheduled page HTML. Persisted runtime state is limited to health metadata such as mode, HTTP status, frame-block reason, timestamps, and bounded error text. The existing offscreen document is reused so Chrome never hosts multiple hidden Constellation runtimes.
