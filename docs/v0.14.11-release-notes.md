# Project Constellation v0.14.11 — Early Branch Guard

## Why this release exists

A real ChatGPT conversation reached the provider banner **“You’ve reached the maximum length for this conversation, but you can keep talking by starting a new chat.”** without Constellation warning early enough. Two gaps combined: that exact provider phrase was not in the hard-limit matcher, and Capacity Guard ignored the transcript’s full active-branch message count even though tool/app messages can consume substantial conversation runway while visible user/assistant turn counts remain modest.

## Fixes

- Health Core v9 counts visible/stored turns, measured characters, full active-branch messages, and structured/tool-app messages.
- Adaptive early-zone thresholds warn before the configured hard handoff boundary when any one pressure lane is climbing quickly.
- ChatGPT transcript metadata now includes structured and tool-message counts; no transcript text or auth material is added to extension state.
- The exact ChatGPT maximum-length banner is recognized as a critical provider hard-limit signal. Provider near-limit wording, when exposed, becomes an immediate handoff warning.
- Default local safety thresholds move earlier. Upgrade migration changes only the untouched legacy default tuple; custom user threshold choices remain custom.
- Capacity attention remains primary over healthy running/tool state, and the existing Branch & continue control becomes urgent before the terminal provider banner.

## Safety

Branching remains explicit-user-only. Passive monitoring never opens, focuses, navigates, reloads, or retries ChatGPT.

## QoL and regression hardening

- Execution Pulse shows **Branch soon** and **Branch now** directly on the action instead of making users decode a hidden warning.
- Safety pressure at/above the configured handoff boundary displays as `100%+`, avoiding confusing 150%/200% meter text.
- DOM-only fallback counting no longer claims full-branch transcript proof.
- Approval Autopilot settings now accurately describe the v0.14.8+ open-tabs-only recovery model; no hidden recovery window is implied.
- Upgrade migration has explicit browser coverage proving the old default tuple advances to the earlier profile while custom thresholds remain untouched.
- All 27 browser smoke workflows pass in bounded local gates, including the exact 130-message early-warning and current ChatGPT maximum-length-banner regressions.
