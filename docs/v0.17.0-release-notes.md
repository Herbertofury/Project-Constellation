# Project Constellation v0.17.0 — Dependency Brain + Guarded Autopilot

## Release intent

v0.17.0 teaches Project Constellation how project work relates across chats without giving it permission to write or send provider-chat content on its own. The project brain may keep learning broadly, while every provider-writing path remains user-reviewed.

## Dependency Brain

Project intelligence now compiles a bounded relationship layer over source-backed knowledge, files, artifacts, versions, and chat activity. It records inferred or explicit dependency edges with provenance and confidence. When newer observed version/dependency evidence makes an older downstream node questionable, the node becomes **possibly stale** instead of being deleted or silently treated as current.

## Version awareness

Version observations are grouped into project/artifact families. Literal observed labels are preserved, and the newest observed item is separated from older observed history. This is an awareness layer, not a claim that every numerically newer artifact is automatically verified-good.

## Cross-chat coordination

- Cross-chat handoffs surface evidence that appears useful to another active/attention chat.
- Duplicate-work prevention identifies likely parallel overlap for review.
- **What changed** reports meaningful project deltas since the user's last explicit caught-up watermark.
- Every inference stays bounded and provenance-backed; inferred overlap is never mislabeled as a confirmed conflict.

## Per-chat Context Packets without brain silos

A chat-specific Context Packet selects a bounded set of task-relevant project evidence. It can also include high-value reusable project-wide lessons learned in other chats—such as performance, compatibility, validation, workflow, recovery, and release patterns. The underlying chat still contributes its extracted knowledge to the full Project Brain, so Context Packets do not fragment learning into isolated mini-brains.

## Guarded Project Autopilot

Project Autopilot may detect, prepare, prioritize, and propose:

- duplicate-work reviews;
- cross-chat handoffs;
- stale dependency/version reviews;
- refreshed per-chat context.

It may **not** send provider messages, silently inject provider context, stop or redirect provider chats, or overwrite unrelated composer text. Provider-writing proposals require explicit review and approval of exact text. Approved text is hash-checked and may only be staged into the exact already-open target chat. The user still presses Send.

Denied proposal fingerprints remain denied unless deliberately reconsidered; changing evidence creates a new proposal fingerprint rather than resurrecting denied text invisibly.

## Provider write safety lock

The legacy Branch & Continue path no longer has any automatic-send branch. Continuation content can be staged/prefilled for review or copied when the provider composer cannot be safely filled. Constellation never presses the provider Send button and never treats Enter interception as permission to send.

## Pulse: Current Chat → Add to Project

The Command/Pulse side panel now exposes the active conversation directly:

- shows the exact active supported AI chat;
- shows its current Constellation project;
- **Add to Project** / **Change project** opens user-created projects;
- **Create + add** creates a new workspace project and attaches the exact chat in the same explicit action;
- supports removal from a project;
- revalidates both the active tab ID and chat ID at commit time, so switching chats during the chooser aborts safely instead of assigning the wrong conversation.

The Projects tab also exposes **Add current chat** shortcuts for existing workspace projects.

## Performance / anti-stall contract

Dependency Brain, version analysis, handoff/duplicate inference, What Changed, and Autopilot proposal generation are bounded organizer/project-room computations. They do not run as provider calls and are not added to the live provider capture critical path. The existing 500-project / 10,000-chat torture fixture remains the regression floor.
