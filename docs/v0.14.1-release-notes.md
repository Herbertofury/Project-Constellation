# Project Constellation v0.14.1 - Live Pulse Hotfix

v0.14.1 repairs the live browser-state layer introduced in v0.14.0. The popup and collapsed Execution Pulse now report the AI chat tabs that are actually open and distinguish active work, attention/stale states, and completed chats from current DOM plus provider-network evidence.

## What changed

- **Real open-tab census:** Chat Pulse now queries every supported AI chat tab instead of reading incompatible historical catalog totals.
- **No reload tax after upgrade:** already-open tabs that still have an older content script are classified through a safe `chrome.scripting` DOM probe, so a hot upgrade can see them immediately.
- **Better ChatGPT completion truth:** stop/stream/busy controls, response/tool network requests, high-confidence present-tense tool labels, and final assistant controls are combined. `Searching Google Drive ...` remains active; a finished `Searched Google Drive ...` step with final controls becomes complete. Historical shimmer text no longer keeps a chat falsely active forever.
- **Hidden-tab tracking:** switching away from an active chat triggers an immediate re-sample plus a lightweight active pulse. Network lifecycle events also trigger bounded reconciliations, allowing background completion notifications without keeping the popup open.
- **Completion notifications:** enabled by default and sent only after an observed active to completed transition.
- **Existing-tab navigation:** clicking a Chat Pulse item focuses its real browser tab instead of opening a duplicate.
- **Editable Branch & Continue:** the default behavior now prefills the new chat for review. Edit freely, press Enter to submit, and use Shift+Enter for a newline. A popup toggle restores automatic sending when desired.
- **Output Vault stays secondary:** saved/page mismatch policy does not replace the primary live chat label. Balanced remains the default sensitivity.

## Test focus

After loading v0.14.1 over v0.14.0, open the popup without reloading your existing ChatGPT tabs. The **Active / Stale / Completed** totals should immediately reflect those open tabs. Start a tool-heavy response, switch to another tab, and confirm it stays Active until the actual response completes; completion should then move the tab to Completed and, when enabled, emit a notification.

For Branch & Continue, keep **Review branched chats before send** enabled, branch a chat, modify the prefilled continuation, press Enter, and confirm the edited text is submitted.
