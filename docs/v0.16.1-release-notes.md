# Project Constellation v0.16.1 — Connected Drive Auto-Sync

v0.16.1 is a reliability follow-up to v0.16.0. It removes a background retry loop that could occur when Project Constellation was built with Google OAuth support but the user had never connected Google Drive.

## Fixed

- **No automatic Drive work before a real connection exists.** A production OAuth client ID now means only that Drive *can* be connected; it no longer counts as evidence that the user *has* connected it.
- **Dirty state is preserved while disconnected.** New projects, chats, checkpoints, and other local changes still mark the Drive snapshot dirty, but Project Constellation does not schedule futile non-interactive sync alarms until there is real connection evidence.
- **Stale Drive alarms are harmless.** An automatic Drive alarm re-checks connection eligibility before changing status or requesting a token. A never-connected or explicitly disconnected user receives a clean no-op instead of an auth failure followed by another 30-minute retry.
- **Explicit disconnect wins over stale IDs.** Disconnect clears the automatic sync alarm and connection marker even if an older folder/file ID remains in settings.
- **Previously connected installs still recover.** A transient Drive error remains retryable when Constellation has durable evidence of a prior successful connection, including a connection timestamp, verified/synced state, existing remote IDs, or prior sync/restore history.
- **Reconnect resumes pending work.** A successful explicit Drive connection records connection evidence and schedules any already-dirty state for sync without requiring another project/chat mutation.

## Verification

- Adds `tests/drive-sync-policy.test.mjs` for never-connected, explicitly disconnected, connected, upgraded legacy, transient-error, disabled-auto-sync, and missing-OAuth cases.
- Routes every automatic Drive scheduler and retry through the same tested policy gate.
- Keeps manual **Connect**, **Sync**, and **Restore** behavior available; the new guard applies only to automatic background Drive work.

This point release does not change the v0.16 multi-tab ChatGPT supervisor, stale-chat rescue, permission autopilot, project discovery, or continuation behavior.
