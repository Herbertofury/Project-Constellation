# Project Constellation v0.16.0 — Living Project Rooms + Safe Router

## Release intent

v0.16.0 turns Project Atlas from an organizer into a more useful project operating surface while preserving user control and chat responsiveness. It deliberately does **not** make project assignment autonomous.

## Safe Project Router

- Runs deterministic local scoring over bounded project/chat evidence.
- Suggests likely project homes with confidence and shared terms.
- Never writes project membership from a suggestion.
- **Confirm project** performs the assignment explicitly.
- **Not this project** records a project + evidence-fingerprint dismissal so the same suggestion does not nag again unchanged.
- Manual Move/drag/bulk assignment remains an explicit user confirmation path.
- Router computation is invoked from organizer/Project Room workflows, not the live chat capture critical path.

## Living Project Room

A selected project now opens a consolidated source-backed room containing:

- next actions and follow-ups;
- decisions;
- live Active and Needs Attention chats;
- bounded multi-chat coordination signals;
- curated Project Brain working memory;
- evidence coverage and memory-policy history;
- latest artifact when available;
- project-scoped search across indexed project evidence.

Every source-backed memory/chat retains direct navigation to its originating chat or artifact when a URL exists.

## Multi-chat coordination

Coordination is intentionally conservative. Active/attention chats are bounded before pair comparison, and only a bounded number of strongest pairs are retained. Shared focus can produce `parallel-overlap`, `handoff-risk`, or `related-work`; the UI does not call an inferred overlap a proven conflict.

## Universal project search

Universal search now accepts a Project Room scope and can return grouped conversation matches plus standalone indexed evidence. Match rows can open their exact stored source, grouped cards can open the exact chat, and command-palette entries can jump directly into the selected Project Room/search flow.

## Scale and anti-stall engineering

A synthetic acceptance test now exercises 500 projects and 10,000 chats plus a large compiled Project Brain with 5,000 knowledge items and 1,500 files. The first implementation exposed a real O(chats × projects × retokenization) waste: the 10,000-chat router pass took roughly 5.2 seconds locally. v0.16.0 now vectorizes each chat once before project comparisons; representative reruns are around 1.0–1.1 seconds on this acceptance host without relaxing the workload or result bounds.

The router caps suggestions and the coordination compiler caps working chats/pairs. These features remain outside live provider capture so a large project catalog does not make active AI chats wait on organizer intelligence.

## Compatibility and preservation

Preserved from earlier releases:

- Project Brain source provenance and memory policy ledger;
- Project + state organization and State-only/Flat compatibility views;
- project-aware native Chrome groups without stealing user-created groups;
- Black Box Truth, Work Rescue, Capacity Guard, Output Vault, Interruption Guardian, Runway Sentinel, and No Surprise Navigation;
- explicit user-owned recovery and provider navigation.
