# Project Constellation v0.18.1 — Runtime Error Hardening

This patch fixes the runtime errors reported from Chrome's extension error page without regressing the v0.18.0 Smart Project Icons + Chat Menu QOL work.

## Fixes

- ChatGPT transcript probe no longer throws `Failed to execute 'postMessage'` when ChatGPT opens same-host estuary/content documents inside an opaque/sandboxed origin.
- Transcript probe exits immediately on `/backend-api/*` and `/api/*` documents because those are not conversation UI surfaces.
- Scheduled Task bridge messages use the same opaque-origin-safe self-window transport.
- The hourly catalog-maintenance alarm once again has a defined `maybeStartAutomaticCatalog()` implementation with due-time, enablement, provider selection, and busy-state guards.
- Automatic catalog sweeps continue to honor `autoSweep`, `intervalHours`, `lastAutoSweepAt`, `providerIds`, and the existing idle-only logic inside the catalog runner.

## Regression coverage

`tests/runtime-error-hardening.test.mjs` pins the two reported bugs so they cannot silently reappear.
